# 하역 순서를 고려한 택배 차량 3D 적재 알고리즘

> 🏆 **포스코 청년 AI·BigData 아카데미 26기 프로젝트 장려상 (2024.07)**

> 여러 배송지를 도는 택배 차량에서, 짐을 **많이 싣는 것**과 **배송지마다 쉽게 내리는 것**을 함께 고려한 3D Bin Packing 휴리스틱

`Python` `NumPy` `Matplotlib` `PyBullet` `OR-Tools` · 포스코 청년 AI·BigData 아카데미 26기 · 6인 팀 · 2024.07

## 1. 문제

택배 차량에 상자를 실을 때 적재율만 높이면, 먼저 내려야 할 상자가 안쪽 깊숙이 들어가는 일이 생깁니다. 그러면 배송지마다 다른 상자를 꺼냈다가 다시 싣는 **재취급(rehandling)**이 반복돼 배송 시간과 작업자 부담이 늘어납니다.

그래서 두 가지를 함께 다뤘습니다.
- **적재(Loading):** 정해진 적재함 안에 상자를 최대한 많이, 안정적으로 싣기
- **하역(Unloading):** 배송지 순서대로 내릴 때 재취급 횟수를 줄이기

## 2. 설정

| 항목 | 값 |
|---|---|
| 적재함 | 170 × 275 × 160 (시뮬레이션에서 0.6배 축소) |
| 상자 | 60개, 규격 6종, 무게 1.7 ~ 10 kg (`boxes_with_locations.json`) |
| 배송지 | 5곳 (`po1` ~ `po5`), 상자마다 배송지 지정 |
| 회전 | 상자마다 6가지 방향 허용 |

## 3. 접근

여러 방법을 시도하며 비교했습니다.

| 단계 | 방법 | 파일 |
|---|---|---|
| 기준선 | 기존 라이브러리(`py3dbp`)로 적재 확인 | `prototype_1.py` |
| 정수계획 | OR-Tools(SCIP)로 배치를 최적화 문제로 정식화 | `test1.py` |
| 서브 볼륨 휴리스틱 | 상자를 놓을 때마다 남은 공간을 서브 볼륨으로 나눠 관리. DBL(Deepest-Bottom-Left)과 빈 공간 점수 기반 배치를 비교 | `prototype_2.py`, `prototyp_3.py` |
| **최종 적재 휴리스틱** | 안쪽부터 행·층 단위로 채우고, 상자 순서를 1,000번 무작위로 바꿔 **적재율이 가장 높은 배치**를 선택. 상자마다 적재 순서와 배송지를 기록 | `heuristics.py` |
| 하역 평가 | 배송지 순서대로 내리면서 **하역 + 임시 하차 + 재적재 횟수**를 세어 재취급 비용을 계산하고 애니메이션으로 확인 | `unloading.py` |
| 물리 시뮬레이션 | PyBullet에 중력을 적용해 적재 상태가 무너지지 않는지, 역순 하역 시 안정한지 확인 | `simulate.py` |

## 4. 결과

`heuristics.py`를 4번 실행한 결과, 상자 60개 중 49 ~ 54개를 실었고 **적재율은 77 ~ 79%**였습니다. 무작위 탐색이라 실행할 때마다 결과가 조금씩 다릅니다.

산출물은 다음과 같습니다.

- 배송지별 색으로 구분한 3D 적재 시각화 (`visualize.py`)
- 상자별 위치·방향·적재 순서·배송지를 담은 적재 계획 (`packed_items.json`)
- 배송지 순서대로 하역하는 과정과 재취급 횟수를 보여주는 애니메이션 (`unloading.py`)
- PyBullet 물리 시뮬레이션으로 적재 안정성 확인 (`simulate.py`)

## 5. 실행

```bash
pip install numpy matplotlib pybullet
python heuristics.py      # 적재 계획 생성 → packed_items.json, 최고 적재율 출력
python visualize.py       # 3D 적재 시각화
python simulate.py        # 물리 시뮬레이션 (GUI)
```

## 6. 한계와 다음 단계

- 현재 최종 휴리스틱은 적재율을 기준으로 배치를 고르고, 하역 비용은 사후에 평가합니다. 다음 단계는 **배송지 순서를 적재 순서에 직접 반영**해 두 목표를 함께 최적화하는 것입니다.
- 무게 중심, 하중 제한(무거운 상자를 아래에), 작업자 동선 같은 휴먼 팩터 제약을 목적 함수에 더 넣을 수 있습니다.
- 무작위 탐색이라 실행마다 결과가 달라집니다. 시드 고정과 반복 실험으로 성능 분포를 보는 것이 필요합니다.
